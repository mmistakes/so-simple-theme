뉴럴디 인턴십에서 베트남 EVN CPC 전주 GPS 좌표 보정과 대표 이미지 정비를 위해 8/18~9/18 한 달간 진행한 작업들을 모았습니다. 분석 방법론(문서)과 자동화 스크립트를 함께 다룹니다.

### 1. GPS 좌표 보정 방법론
- 전력청 GPS · 당사 시스템 GPS · 실측(수기) GPS 3종을 비교하고, 실측 37개 전주를 기준점으로 오차 원인 분석
- 촬영 품질(속도·카메라 각도) 필터링 → 날짜별 쏠림 보정 → 진행방향 기준 거리가중 보정까지 4단계 알고리즘 설계
- **검증셋 37개 기준 평균 오차 5.2m → 2.5m로 개선** (2m 목표 달성률 5% → 51%)
- 검증 도로 인근 276개는 전량 보정 적용, 551개는 원본 유지, 338개는 부분 적용 — 검증 범위 밖 지역까지 과확장 적용하지 않았다는 점을 결론에 명시
- 보정 전/후 위치를 OSM 도로망 대비 인터랙티브 지도로 시각화

### 2. 전주 번호 재정리
전력청 원본 번호 체계와 검수 과정에서 새로 매긴 번호 체계가 서로 달라 발생한 혼선을, 매핑 테이블로 1:1 정리

### 3. 불량 유형별 검수자료 PPT 자동생성
클래스 0~12(불량 유형)별로 원본 촬영 이미지 + 100% 확대 인셋 + bbox + 화살표를 pptxgenjs로 자동 배치. 확대 인셋은 bbox 영역을 가리지 않는 코너를 자동 탐색해 배치하고(겹치면 축소 후 재탐색)

### 4. 재검수용 로컬 웹 도구
Flask 기반 로컬 서버로, 대표 GPS 엑셀을 읽어 전주별 사진 갤러리, 인접 전주 경고(30m 이내 다른 전주 존재 시 표시), 메모/플래그 남기기, 검수 결과 CSV 내보내기 기능 제공

### Stack
Python(openpyxl, Flask), Node.js(pptxgenjs), 순수 HTML/CSS/JS
